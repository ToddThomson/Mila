# Governance

Larkspur has four maintainers: Ines Okafor, Tomasz Wilk, Priya Raman and Dele Mensah.

Any change to configuration, the job format or the worker's command line starts as an RFC in `rfcs/`. Anyone
may write one. An RFC is discussed at the fortnightly maintainers' meeting and is accepted when one maintainer
approves it there; the minutes record who. A maintainer may not approve an RFC they wrote.

Accepted RFCs name a target release, but the release notes are the record of what actually shipped, and when.
